### OldPhone 📱

OldPhone is a **C# application** designed to manage and work with old phone-related data efficiently.  
This project demonstrates core C# development concepts such as object-oriented programming, data handling, and user-friendly application design.

## Features ✨

- Add and manage phone records
- View phone details
- Update existing phone information
- Delete phone entries
- Simple and clean user interface
- Fast and efficient data handling
